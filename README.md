# 地铁·趣味换乘

一个基于 AstrBot 的趣味换乘游戏插件。说出换乘站名即可参与游戏，支持 **广州地铁** 和 **深圳地铁** 双数据集切换。

## 功能特点

- 🚇 **双数据集** — 支持广州地铁（含广佛线/佛山2/3号线）和深圳地铁，随时切换
- 🎮 **游戏机制** — 开始游戏后发送含换乘站的消息即可"找到"该站，清空所有车站即获胜
- 👥 **多人同乐** — 群聊中多人参与，排行榜记录每位玩家的贡献
- 🚉 **同线提示** — 找到车站后自动提示同线路其他未找到的换乘站
- 🔄 **数据拓展** — 可轻松添加其他城市地铁数据集

## 安装方法

1. 将整个 `地铁·趣味换乘` 文件夹复制到 AstrBot 插件目录：
   ```
   data/plugins/地铁·趣味换乘/
   ```
2. 重启 AstrBot 服务
3. 在 AstrBot 管理界面启用该插件

## 使用说明

### 游戏控制指令

| 指令 | 功能 |
|------|------|
| `!metro_start` | 开始游戏 |
| `!metro_stop` | 停止游戏 |
| `!metro_status` | 查看当前状态 |
| `!metro_list` | 查看剩余车站列表 |
| `!metro_found` | 查看已找到的车站 |
| `!metro_rank` | 查看排行榜 |
| `!metro_datasets` | 查看可用数据集 |
| `!metro_switch <名称>` | 切换数据集 |
| `!metro_help` | 显示帮助信息 |

### 使用示例

```
玩家: !metro_start
Bot: 🚇 地铁·趣味换乘游戏开始！
     当前数据集：广州地铁
     ...

玩家: 公园前
Bot: ✅ 您现在在公园前
     🚇 同线网上还未使用的换乘站：1号线：体育西路、广州东站...

玩家: !metro_rank
Bot: 🏆 地铁换乘游戏排行榜：
     🥇 用户xxx: 5个
```

### 切换数据集

```
!metro_stop           → 先停止游戏
!metro_switch 深圳地铁 → 切换为深圳地铁数据
!metro_start          → 开始深圳地铁游戏
```

## 包含的数据集

### 广州地铁（默认）
- **86 个换乘站**，覆盖 22 条线路
- 含广州地铁 1~22 号线、广佛线、APM线、佛山2号线、佛山3号线

### 深圳地铁
- **60 个换乘站**，覆盖 17 条线路
- 含深圳地铁 1~20 号线

## 游戏规则

1. 开始游戏后，Bot 会发布所有换乘站的完整列表
2. 当您发送的消息中包含列表中的换乘站时，该站将从列表中删除
3. 同时会提示同线路其他还未找到的换乘站
4. 清空所有换乘站即为胜利！
5. 找到车站的玩家会被记录在排行榜中
6. 游戏可以多人一起玩

## 小贴士

- 发送完整的车站名称即可匹配
- 可以一次发送包含多个车站的消息，批量查找
- 使用 `!metro_switch` 可在广州/深圳数据间切换
