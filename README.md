# 地铁游园

一个基于 AstrBot 的 **双人联机对战** 地铁换乘策略游戏。基于 **2027年广州地铁线网图**，包含BP选区、必须换乘、打击车站、有轨/APM卡牌系统。

## 功能特点

- 🚇 **2027版线网** — 含12号线中段、13号线西段、18号线北段、22号线北段，3号线支线已拆解给10号线
- 🏛️ **BP选区阶段** — 双方轮流ban线ban站、选目的地车站、选出发行政区、选起始车站
- 🔄 **必须换乘** — 每次移动后必须换乘到不同线路，不能连续同线路
- ⚡ **打击车站** — 含目的地线路的车站形成打击，对方须避开
- 🎴 **有轨/APM卡牌** — APM、THZ1、THP1、THP2、TNH1五种卡牌，不能连续使用
- 🗺️ **行政区限定** — 出发车站限定在选定行政区内

## 安装方法

1. 将 `Metro_Garden_transfer` 文件夹复制到 AstrBot 插件目录
2. 重启 AstrBot 服务
3. 在管理界面启用该插件

## 使用说明

### BP流程

| 指令 | 功能 |
|------|------|
| `/metro_join` | 加入等待队列 |
| `/metro_leave` | 离开等待队列 |
| `/metro_start` | 开始BP阶段（需2人加入） |
| `/metro_banline <线路名>` | ban一条线路（或 `skip` 跳过） |
| `/metro_bantransfer <线1> <线2>` | ban线路对（飞站效果，或 `skip` 跳过） |
| `/metro_dest <站名>` | 选择目的地车站 |
| `/metro_district <行政区>` | 选择出发行政区 |
| `/metro_startat <站名>` | 选择起始车站 |

### 对战命令

| 指令 | 功能 |
|------|------|
| 发送换乘站名 | 移动到该车站 |
| 发送 `卡牌转线路`（如 `THP1转7号线`） | 使用有轨/APM卡牌转线 |
| `/metro_use <卡牌> <线路>` | 使用有轨/APM卡牌转线（命令形式） |
| `/metro_stop` | 停止对战 |
| `/metro_status` | 查看对战状态 |
| `/metro_list` | 查看可用换乘站 |
| `/metro_help` | 显示帮助 |

### 有轨/APM卡牌

| 卡牌 | 覆盖线路 |
|------|----------|
| APM | 1号线、3号线、5号线、12号线、13号线 |
| THZ1 | 3号线、4号线、8号线、11号线、12号线 |
| THP1 | 6号线、7号线、21号线 |
| THP2 | 6号线、13号线 |
| TNH1 | 广佛线、佛山2号线 |

## 游戏规则

1. **BP阶段**：双方轮流ban线、ban站，选目的地车站，A选行政区，B在行政区内选起始车站
2. **必须换乘**：每次移动到换乘站后必须换乘到不同线路（不能连续同线路移动）
3. **打击车站**：含目的地线路的车站=打击车站，对方下一步须避开该线路
4. **消耗机制**：每个换乘站和卡牌只能使用一次
5. **获胜条件**：抵达己方目的地车站即获胜；误入对方目的地则对方获胜
6. **卡牌限制**：有轨与APM不得连用（卡牌不能连续两回合使用）
